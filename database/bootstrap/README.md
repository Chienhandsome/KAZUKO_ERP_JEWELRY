# Clean first-run database, schema v93

schema-v93.sql is a metadata-only isql extraction of the verified v93 schema.
It has no CREATE DATABASE path, row data, user credentials or source identity
generator counters. Identity columns start at 1. The initial migrations 1–29
are not present in this repository, so replaying the migration directory alone
cannot create an empty database.

system-v93.sql contains only system permission definitions and the v1–93
migration ledger (no original application timestamps). defaults-v93.sql contains
explicit generic company, branch, warehouses and catalogs. Administrator password
hash/salt and group permissions are generated by LocalDatabaseBootstrapper at
runtime. Other business tables start empty. The walk-in customer has no contact
information, history or opening balance.

All three resources are embedded in Infrastructure. Bootstrap executes them only
against a brand-new staging database, checks schema/admin, then moves the file
without overwrite and publishes a non-secret connection profile. Existing DBs
are not migrated/reset by this feature. Setup builds reject a migration version
newer than this baseline until the clean baseline is refreshed and tested.

Execution uses the provider's FbScript/FbBatchExecution in the application process;
the Windows host manifest selects UTF-8 on Windows 10 1903+. No schema execution
is delegated to isql's ANSI command line. This supports Vietnamese profile paths.

To refresh after a future schema change, extract metadata from a verified test89
restore using isql -x, remove its CREATE DATABASE comment/source path, update the
ledger and reviewed defaults, and increment the baseline version in code/build.
Never export users, customers, suppliers, prices, inventory, documents, settings,
print templates, media paths or account password hashes as seed data.

Run tests/Kazuko.LocalDatabase.IntegrationChecks from the repository root. It uses
only new isolated test89 databases under artifacts and does not publish a profile
into the user's real LocalAppData.
